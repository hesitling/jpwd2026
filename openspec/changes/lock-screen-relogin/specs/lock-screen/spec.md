## 新增需求

### 需求:锁定后显示 LockPanel
当会话被锁定或超时时，系统必须显示 LockPanel 而非 LoginPanel。

#### 场景:用户手动锁定
- **当** 用户点击"锁定"菜单项
- **那么** 系统必须显示 LockPanel，隐藏密码输入框

#### 场景:会话超时锁定
- **当** 会话因超时被销毁
- **那么** 系统必须自动显示 LockPanel

### 需求:LockPanel 显示欢迎信息
LockPanel 必须显示锁定前的用户名作为欢迎信息。

#### 场景:显示欢迎信息
- **当** LockPanel 显示时
- **那么** 必须显示"欢迎回来，{username}"格式的欢迎信息

### 需求:解锁验证密码
用户在 LockPanel 输入密码后，系统必须验证密码并恢复会话。

#### 场景:密码正确解锁成功
- **当** 用户输入正确的主密码并点击解锁
- **那么** 系统必须创建新会话并显示 VaultPanel

#### 场景:密码错误解锁失败
- **当** 用户输入错误的主密码并点击解锁
- **那么** 系统必须显示错误信息"密码错误"，保持在 LockPanel

#### 场景:密码为空时提示
- **当** 用户未输入密码直接点击解锁
- **那么** 系统必须显示提示"请输入主密码"

### 需求:锁定时保存用户名
系统必须在锁定前保存当前用户的用户名，用于解锁时的欢迎信息和验证。

#### 场景:锁定时保存用户名
- **当** 会话被锁定（手动或超时）
- **那么** 系统必须保存当前用户名到 lockedUsername 字段
