## 新增需求

### 需求:系统必须提供密码详情对话框
系统必须提供一个专门的对话框用于显示密码条目的完整信息，支持只读查看。

#### 场景:用户双击密码条目查看详情
- **当** 用户双击 PasswordTable 中的密码条目
- **那么** 系统必须显示 PasswordDetailDialog，显示该密码条目的所有字段

#### 场景:密码详情对话框显示所有字段
- **当** PasswordDetailDialog 显示
- **那么** 对话框必须显示以下字段：标题、用户名、密码（默认隐藏）、URL、分类、备注、创建时间、更新时间

#### 场景:密码详情对话框支持复制操作
- **当** 用户点击密码详情对话框中的"复制"按钮
- **那么** 系统必须将对应的字段值复制到剪贴板

#### 场景:密码详情对话框支持显示/隐藏密码
- **当** 用户点击密码详情对话框中的"显示密码"按钮
- **那么** 系统必须切换密码的显示状态（明文/隐藏）

#### 场景:密码详情对话框支持编辑操作
- **当** 用户点击密码详情对话框中的"编辑"按钮
- **那么** 系统必须关闭详情对话框并打开 PasswordDialog（编辑模式）

#### 场景:密码详情对话框支持关闭操作
- **当** 用户点击密码详情对话框中的"关闭"按钮或按 Escape 键
- **那么** 系统必须关闭密码详情对话框
