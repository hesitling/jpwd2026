## 新增需求

### 需求:MainFrame 必须连接所有菜单和工具栏功能
MainFrame 中的所有菜单项和工具栏按钮必须连接到实际的功能实现，禁止显示"待实现"的提示对话框。

#### 场景:用户点击添加密码菜单项
- **当** 用户点击"编辑"菜单中的"添加密码"菜单项
- **那么** 系统必须显示 PasswordDialog（添加模式）

#### 场景:用户点击编辑密码菜单项
- **当** 用户点击"编辑"菜单中的"编辑密码"菜单项
- **那么** 系统必须显示 PasswordDialog（编辑模式），并加载当前选中的密码条目

#### 场景:用户点击删除密码菜单项
- **当** 用户点击"编辑"菜单中的"删除密码"菜单项
- **那么** 系统必须显示确认对话框，确认后删除当前选中的密码条目

#### 场景:用户点击设置菜单项
- **当** 用户点击"编辑"菜单中的"设置"菜单项
- **那么** 系统必须显示 SettingsDialog

#### 场景:用户点击搜索按钮
- **当** 用户点击工具栏中的"搜索"按钮
- **那么** 系统必须将焦点设置到 VaultPanel 的搜索框

#### 场景:用户点击刷新菜单项
- **当** 用户点击"视图"菜单中的"刷新"菜单项
- **那么** 系统必须刷新密码列表和分类树

### 需求:MainFrame 必须实现删除密码功能
MainFrame 必须提供删除密码的功能，删除前必须显示确认对话框。

#### 场景:用户删除选中的密码条目
- **当** 用户选择一个或多个密码条目并触发删除操作
- **那么** 系统必须显示确认对话框，显示将要删除的密码条目数量

#### 场景:用户确认删除
- **当** 用户在确认对话框中点击"是"
- **那么** 系统必须删除选中的密码条目并刷新列表

#### 场景:用户取消删除
- **当** 用户在确认对话框中点击"否"
- **那么** 系统必须取消删除操作，不删除任何密码条目

### 需求:MainFrame 必须实现数据刷新功能
MainFrame 必须提供刷新数据的功能，刷新密码列表和分类树。

#### 场景:用户触发刷新操作
- **当** 用户点击"视图"菜单中的"刷新"菜单项或按 F5 键
- **那么** 系统必须重新加载密码列表和分类树

#### 场景:刷新完成后显示状态
- **当** 数据刷新完成
- **那么** 系统必须在状态栏显示刷新结果（如"已加载 X 个密码条目"）
