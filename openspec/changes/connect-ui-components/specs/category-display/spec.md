## 新增需求

### 需求:PasswordTable 必须显示实际的分类名称
PasswordTable 的分类列必须显示密码条目所属分类的实际名称，而不是硬编码的"分类"或"未分类"。

#### 场景:密码条目有分类
- **当** 密码条目设置了分类（categoryId 不为 null）
- **那么** PasswordTable 的分类列必须显示该分类的实际名称

#### 场景:密码条目无分类
- **当** 密码条目未设置分类（categoryId 为 null）
- **那么** PasswordTable 的分类列必须显示"未分类"

#### 场景:分类被删除后密码条目的显示
- **当** 密码条目引用的分类已被删除
- **那么** PasswordTable 的分类列必须显示"未分类"

#### 场景:分类名称更新后密码条目的显示
- **当** 分类名称被更新
- **那么** PasswordTable 必须在下次刷新时显示更新后的分类名称

### 需求:PasswordTable 必须支持分类筛选
PasswordTable 必须支持按分类筛选密码条目。

#### 场景:用户选择分类进行筛选
- **当** 用户在 VaultPanel 的分类树中选择一个分类
- **那么** PasswordTable 必须只显示该分类下的密码条目

#### 场景:用户选择"所有分类"
- **当** 用户在 VaultPanel 的分类树中选择"所有分类"
- **那么** PasswordTable 必须显示所有密码条目
