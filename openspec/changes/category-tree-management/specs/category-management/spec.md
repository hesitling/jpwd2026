## 修改需求

### 需求:分类管理界面
系统必须提供分类管理入口。分类树面板底部必须提供添加和删除按钮。分类树节点必须支持双击内联编辑。界面必须显示每个分类的名称和颜色标记。

#### 场景:分类管理界面显示
- **当** 用户进入密码库面板
- **那么** 左侧显示分类树
- **那么** 分类树底部显示「添加」和「删除」按钮
- **那么** 每个分类节点显示名称和颜色圆点（如有）

#### 场景:通过分类树添加分类
- **当** 用户点击分类树底部的「添加」按钮
- **当** 用户输入分类名称并确认
- **那么** 系统创建新分类
- **那么** 分类树刷新显示

#### 场景:通过分类树编辑分类
- **当** 用户双击分类树中的某个分类节点
- **当** 用户修改名称并按 Enter 确认
- **那么** 系统验证名称合法性
- **那么** 系统更新分类信息
- **那么** 树节点显示更新后的名称

#### 场景:通过分类树删除分类
- **当** 用户选中分类树中的某个分类节点
- **当** 用户点击「删除」按钮
- **当** 用户确认删除
- **那么** 系统删除分类
- **那么** 分类树刷新显示
