## 新增需求

### 需求:分类树添加按钮
分类树面板底部必须显示「添加」按钮。点击按钮后必须弹出输入框让用户输入分类名称。添加成功后必须刷新分类树。

#### 场景:点击添加按钮
- **当** 用户点击分类树底部的「添加」按钮
- **那么** 系统弹出输入对话框
- **那么** 对话框提示"请输入分类名称"

#### 场景:成功添加分类
- **当** 用户在输入对话框中输入非空的分类名称
- **当** 该名称不与现有分类重复
- **当** 用户点击确定
- **那么** 系统创建新分类
- **那么** 分类树刷新显示新分类
- **那么** 新分类节点可见

#### 场景:添加时名称为空
- **当** 用户在输入对话框中未输入任何内容
- **当** 用户点击确定
- **那么** 系统不创建分类
- **那么** 系统显示错误提示"分类名称不能为空"

#### 场景:添加时名称重复
- **当** 用户在输入对话框中输入已存在的分类名称
- **当** 用户点击确定
- **那么** 系统不创建分类
- **那么** 系统显示错误提示"分类名称已存在"

#### 场景:取消添加
- **当** 用户在输入对话框中点击取消
- **那么** 系统不创建分类
- **那么** 分类树不做任何变更

### 需求:分类树删除按钮
分类树面板底部必须显示「删除」按钮。按钮必须仅在选中有效分类节点时启用。删除前必须检查分类下是否有密码条目并相应提示用户。删除后必须刷新分类树。

#### 场景:删除按钮初始状态
- **当** 分类树加载完成
- **当** 未选中任何分类节点
- **那么** 「删除」按钮必须处于禁用状态

#### 场景:选中分类节点后启用删除按钮
- **当** 用户选中某个分类节点
- **那么** 「删除」按钮必须变为启用状态

#### 场景:选中根节点后禁用删除按钮
- **当** 用户选中"所有分类"根节点
- **那么** 「删除」按钮必须处于禁用状态

#### 场景:删除无关联条目的分类
- **当** 用户选中一个分类节点
- **当** 该分类下没有关联的密码条目
- **当** 用户点击「删除」按钮
- **那么** 系统显示确认对话框"确定删除分类 'xxx'？"
- **当** 用户确认删除
- **那么** 系统删除该分类
- **那么** 分类树刷新，该分类不再显示

#### 场景:删除有关联条目的分类
- **当** 用户选中一个分类节点
- **当** 该分类下有关联的密码条目
- **当** 用户点击「删除」按钮
- **那么** 系统显示确认对话框"分类 'xxx' 下有 N 个密码条目，删除后将变为未分类。确定删除？"
- **当** 用户确认删除
- **那么** 系统将关联的密码条目设为未分类
- **那么** 系统删除该分类
- **那么** 分类树刷新，该分类不再显示

#### 场景:取消删除
- **当** 用户在确认对话框中点击取消
- **那么** 系统不删除分类
- **那么** 分类树不做任何变更

### 需求:添加和删除后全量重建分类树
添加或删除分类后，系统必须全量重建分类树。重建后必须自动展开所有节点。

#### 场景:添加后重建
- **当** 新分类创建成功
- **那么** 系统重新加载所有分类数据
- **那么** 系统重建分类树
- **那么** 所有节点处于展开状态

#### 场景:删除后重建
- **当** 分类删除成功
- **那么** 系统重新加载所有分类数据
- **那么** 系统重建分类树
- **那么** 所有节点处于展开状态
