## 新增需求

### 需求:分类树节点内联编辑
系统必须允许用户在分类树中双击分类节点进入内联编辑模式。编辑模式下必须显示文本输入框，预填当前分类名称。用户必须可以通过按 Enter 键或点击其他区域确认编辑。用户必须可以通过按 Escape 键取消编辑。

#### 场景:进入编辑模式
- **当** 用户双击分类树中的某个分类节点
- **那么** 该节点变为文本输入框
- **那么** 文本框预填当前分类名称
- **那么** 文本框内容处于全选状态

#### 场景:成功重命名
- **当** 用户在编辑模式下输入新的分类名称
- **当** 新名称非空且不与其他分类重名
- **当** 用户按下 Enter 键
- **那么** 系统更新数据库中的分类名称
- **那么** 树节点显示更新后的名称
- **那么** 编辑模式退出

#### 场景:名称未变更
- **当** 用户在编辑模式下未修改分类名称
- **当** 用户按下 Enter 键或点击其他区域
- **那么** 系统不做任何数据库操作
- **那么** 编辑模式退出

#### 场景:名称为空
- **当** 用户在编辑模式下清空文本框
- **当** 用户按下 Enter 键
- **那么** 系统显示错误提示"分类名称不能为空"
- **那么** 编辑模式保持，用户可继续输入

#### 场景:名称重复
- **当** 用户在编辑模式下输入已存在的分类名称
- **当** 用户按下 Enter 键
- **那么** 系统显示错误提示"分类名称已存在"
- **那么** 编辑模式保持，用户可继续输入

#### 场景:取消编辑
- **当** 用户在编辑模式下按下 Escape 键
- **那么** 编辑被取消
- **那么** 树节点恢复显示原始分类名称
- **那么** 不执行任何数据库操作

### 需求:分类节点颜色显示
系统必须在分类树节点的分类名称左侧显示颜色圆点。圆点颜色必须与分类的 color 属性一致。根节点"所有分类"必须不显示颜色圆点。

#### 场景:显示带颜色的分类节点
- **当** 分类树加载完成
- **当** 某个分类设置了 color 属性
- **那么** 该分类节点名称左侧显示一个颜色圆点
- **那么** 圆点颜色与分类的 color 属性一致

#### 场景:显示无颜色的分类节点
- **当** 分类树加载完成
- **当** 某个分类未设置 color 属性
- **那么** 该分类节点仅显示名称文本
- **那么** 不显示颜色圆点

### 需求:分类节点数据模型
分类树的每个节点必须存储完整的 Category 对象（包含 id、name、color）。选择监听器必须直接从节点获取 Category 对象进行筛选，不得通过分类名称反查 ID。

#### 场景:节点存储 Category 对象
- **当** 分类树加载完成
- **当** 用户检查任意分类节点的内部数据
- **那么** 节点的 userObject 必须为 Category 对象
- **那么** Category 对象包含 id、name、color 属性

#### 场景:筛选使用 Category ID
- **当** 用户选中某个分类节点
- **那么** 系统从节点的 Category 对象中直接获取 id
- **那么** 系统使用该 id 过滤密码条目列表
- **那么** 系统不执行按名称查找分类的数据库查询
