## 新增需求

### 需求:密码复制
系统必须允许用户复制密码到剪贴板。复制时必须使用系统剪贴板。复制后必须显示成功消息。复制后必须启动自动清除计时器。

#### 场景:复制密码
- **当** 用户选择密码条目
- **当** 用户点击复制密码按钮
- **那么** 系统将密码复制到系统剪贴板
- **那么** 系统显示成功消息"密码已复制"
- **那么** 系统启动自动清除计时器

#### 场景:复制用户名
- **当** 用户选择密码条目
- **当** 用户点击复制用户名按钮
- **那么** 系统将用户名复制到系统剪贴板
- **那么** 系统显示成功消息"用户名已复制"
- **那么** 系统不启动自动清除计时器（用户名不是敏感信息）

### 需求:自动清除
系统必须支持剪贴板自动清除。清除时间必须可配置。清除后必须显示提示消息。默认清除时间为30秒。

#### 场景:自动清除
- **当** 用户复制密码到剪贴板
- **当** 配置的清除时间到达
- **那么** 系统自动清除剪贴板
- **那么** 系统显示提示消息"剪贴板已清除"

#### 场景:清除时间配置
- **当** 用户在设置中修改清除时间
- **当** 用户保存设置
- **那么** 系统更新配置文件中的清除时间
- **那么** 后续复制使用新的清除时间

### 需求:手动清除
系统必须允许用户手动清除剪贴板。手动清除必须立即执行。手动清除后必须显示提示消息。

#### 场景:手动清除
- **当** 用户点击清除剪贴板按钮
- **那么** 系统立即清除剪贴板
- **那么** 系统显示提示消息"剪贴板已清除"

#### 场景:快捷键清除
- **当** 用户按下清除快捷键（如Ctrl+Shift+C）
- **那么** 系统立即清除剪贴板
- **那么** 系统显示提示消息"剪贴板已清除"

### 需求:剪贴板监控
系统必须监控剪贴板状态。监控必须检测剪贴板内容变化。监控必须识别密码管理器复制的内容。

#### 场景:剪贴板内容监控
- **当** 系统运行时
- **那么** 系统监控剪贴板内容变化
- **当** 剪贴板内容被其他程序修改
- **那么** 系统取消自动清除计时器

#### 场景:密码管理器内容识别
- **当** 系统复制密码到剪贴板
- **那么** 系统标记剪贴板内容为敏感信息
- **当** 其他程序修改剪贴板
- **那么** 系统识别内容已被覆盖
- **那么** 系统取消自动清除计时器

### 需求:复制历史
系统必须记录复制历史。历史必须包括复制时间和内容类型。历史必须存储在内存中，不持久化。历史必须在应用程序关闭时清除。

#### 场景:记录复制历史
- **当** 用户复制密码或用户名
- **那么** 系统记录复制时间
- **那么** 系统记录内容类型（密码或用户名）
- **那么** 系统将记录添加到历史列表

#### 场景:查看复制历史
- **当** 用户打开复制历史界面
- **那么** 系统显示最近的复制记录
- **那么** 记录显示时间和内容类型
- **那么** 记录不显示实际内容（安全考虑）

### 需求:剪贴板安全
系统必须确保剪贴板操作的安全性。复制时必须使用安全的方式。清除时必须确保数据无法恢复。系统必须避免在日志中记录剪贴板内容。

#### 场景:安全复制
- **当** 系统复制密码到剪贴板
- **那么** 系统使用系统剪贴板API
- **那么** 系统不记录实际密码内容
- **那么** 系统只记录操作类型和时间

#### 场景:安全清除
- **当** 系统清除剪贴板
- **那么** 系统使用空字符串覆盖剪贴板
- **那么** 系统确保数据无法被恢复
- **那么** 系统不记录清除的密码内容

### 需求:复制确认
系统必须在复制敏感信息前确认。确认对话框必须显示警告消息。用户必须明确确认复制操作。

#### 场景:复制确认对话框
- **当** 用户点击复制密码按钮
- **那么** 系统显示确认对话框
- **那么** 对话框显示警告消息"密码将被复制到剪贴板"
- **当** 用户确认
- **那么** 系统执行复制操作
- **当** 用户取消
- **那么** 系统不执行复制操作

#### 场景:配置跳过确认
- **当** 用户在设置中禁用复制确认
- **当** 用户点击复制密码按钮
- **那么** 系统直接执行复制操作
- **那么** 系统不显示确认对话框
