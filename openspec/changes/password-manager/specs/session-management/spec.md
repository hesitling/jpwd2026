## 新增需求

### 需求:会话超时
系统必须支持会话超时。超时时间必须可配置。超时后必须自动锁定应用程序。锁定时必须清除内存中的敏感数据。

#### 场景:超时锁定
- **当** 用户在配置的超时时间内没有操作
- **那么** 系统自动锁定应用程序
- **那么** 系统清除内存中的派生密钥
- **那么** 系统显示锁定界面
- **那么** 用户需要重新输入主密码解锁

#### 场景:活动重置
- **当** 用户进行任何操作（点击、输入等）
- **那么** 系统重置超时计时器
- **那么** 超时计时重新开始

### 需求:超时配置
系统必须允许用户配置超时时间。配置必须支持分钟为单位。配置必须保存到配置文件。默认超时时间为5分钟。

#### 场景:配置超时时间
- **当** 用户在设置中修改超时时间
- **当** 用户保存设置
- **那么** 系统更新配置文件中的超时时间
- **那么** 后续会话使用新的超时时间

#### 场景:默认超时时间
- **当** 用户首次使用应用程序
- **那么** 系统使用默认超时时间5分钟
- **那么** 用户可以在设置中修改

### 需求:活动监控
系统必须监控用户活动。监控必须包括鼠标点击、键盘输入、界面操作。监控必须更新最后活动时间。

#### 场景:鼠标活动监控
- **当** 用户点击界面任何位置
- **那么** 系统记录活动时间
- **那么** 系统重置超时计时器

#### 场景:键盘活动监控
- **当** 用户在界面中输入内容
- **那么** 系统记录活动时间
- **那么** 系统重置超时计时器

#### 场景:界面操作监控
- **当** 用户进行界面操作（如切换标签页、滚动等）
- **那么** 系统记录活动时间
- **那么** 系统重置超时计时器

### 需求:锁定界面
系统必须提供锁定界面。锁定界面必须显示应用程序名称。锁定界面必须提供密码输入框。锁定界面必须提供解锁按钮。

#### 场景:锁定界面显示
- **当** 应用程序被锁定
- **那么** 系统显示锁定界面
- **那么** 界面显示应用程序名称"密码管理器"
- **那么** 界面显示密码输入框
- **那么** 界面显示解锁按钮

#### 场景:解锁成功
- **当** 用户在锁定界面输入正确的主密码
- **当** 用户点击解锁按钮
- **那么** 系统验证主密码
- **那么** 系统重新派生加密密钥
- **那么** 系统解锁应用程序
- **那么** 系统显示主界面

#### 场景:解锁失败
- **当** 用户在锁定界面输入错误的主密码
- **当** 用户点击解锁按钮
- **那么** 系统显示错误消息"密码错误"
- **那么** 系统保持锁定状态

### 需求:手动锁定
系统必须允许用户手动锁定应用程序。手动锁定必须立即清除敏感数据。手动锁定后必须显示锁定界面。

#### 场景:手动锁定
- **当** 用户点击锁定按钮
- **那么** 系统立即锁定应用程序
- **那么** 系统清除内存中的派生密钥
- **那么** 系统显示锁定界面

#### 场景:快捷键锁定
- **当** 用户按下锁定快捷键（如Ctrl+L）
- **那么** 系统立即锁定应用程序
- **那么** 系统清除内存中的派生密钥
- **那么** 系统显示锁定界面

### 需求:会话状态显示
系统必须显示会话状态。状态必须包括剩余时间。状态必须包括锁定状态。状态必须实时更新。

#### 场景:剩余时间显示
- **当** 应用程序处于解锁状态
- **那么** 系统在状态栏显示剩余时间
- **那么** 剩余时间实时更新

#### 场景:锁定状态显示
- **当** 应用程序被锁定
- **那么** 系统显示锁定状态
- **那么** 系统隐藏主界面内容

### 需求:敏感数据清除
系统必须在锁定时清除敏感数据。清除必须包括派生的加密密钥。清除必须包括剪贴板中的密码。清除必须包括内存中的密码缓存。

#### 场景:内存清除
- **当** 应用程序被锁定
- **那么** 系统清除内存中的派生加密密钥
- **那么** 系统清除内存中的密码缓存
- **那么** 系统清除剪贴板中的密码

#### 场景:安全清除
- **当** 应用程序被锁定
- **那么** 系统使用安全的方式清除敏感数据
- **那么** 系统确保数据无法被恢复
