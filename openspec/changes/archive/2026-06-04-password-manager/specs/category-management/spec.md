## 新增需求

### 需求:分类创建
系统必须允许用户创建自定义分类。分类必须包含名称。分类名称必须唯一（每个用户）。分类可以包含可选的颜色。

#### 场景:成功创建分类
- **当** 用户输入分类名称
- **当** 用户选择可选的颜色
- **当** 用户点击保存按钮
- **那么** 系统创建新分类
- **那么** 系统显示成功消息

#### 场景:分类名称已存在
- **当** 用户输入已存在的分类名称
- **当** 用户点击保存按钮
- **那么** 系统显示错误消息"分类名称已存在"

#### 场景:分类名称为空
- **当** 用户未输入分类名称
- **当** 用户点击保存按钮
- **那么** 系统显示错误消息"分类名称不能为空"

### 需求:分类读取
系统必须允许用户查看所有分类。查看时必须显示分类名称和颜色。分类列表必须按名称排序。

#### 场景:查看分类列表
- **当** 用户进入分类管理界面
- **那么** 系统显示所有分类的列表
- **那么** 列表显示分类名称和颜色
- **那么** 列表按名称字母顺序排序

### 需求:分类更新
系统必须允许用户更新分类。更新时必须验证名称唯一性。更新不能影响已关联的密码条目。

#### 场景:成功更新分类
- **当** 用户修改分类名称或颜色
- **当** 用户点击保存按钮
- **那么** 系统验证名称唯一性
- **那么** 系统更新分类信息
- **那么** 系统显示成功消息

#### 场景:更新为已存在的名称
- **当** 用户修改分类名称为已存在的名称
- **当** 用户点击保存按钮
- **那么** 系统显示错误消息"分类名称已存在"

### 需求:分类删除
系统必须允许用户删除分类。删除前必须检查是否有密码条目使用该分类。如果有密码条目使用，必须提示用户。

#### 场景:删除未使用的分类
- **当** 用户选择删除分类
- **当** 该分类没有关联的密码条目
- **当** 用户确认删除
- **那么** 系统删除分类
- **那么** 系统显示成功消息

#### 场景:删除使用的分类
- **当** 用户选择删除分类
- **当** 该分类有关联的密码条目
- **那么** 系统显示警告消息"该分类有X个密码条目"
- **那么** 系统询问用户是否继续删除
- **当** 用户确认删除
- **那么** 系统将关联的密码条目设为未分类
- **那么** 系统删除分类

### 需求:分类关联
系统必须允许用户将密码条目关联到分类。关联时可以选择分类或设为未分类。一个密码条目只能属于一个分类。

#### 场景:关联密码条目到分类
- **当** 用户编辑密码条目
- **当** 用户选择分类
- **当** 用户保存密码条目
- **那么** 系统将密码条目关联到所选分类

#### 场景:取消分类关联
- **当** 用户编辑密码条目
- **当** 用户选择"未分类"
- **当** 用户保存密码条目
- **那么** 系统取消密码条目的分类关联

### 需求:分类过滤
系统必须允许用户按分类过滤密码条目。过滤时必须显示所选分类的所有条目。必须支持显示所有条目。

#### 场景:按分类过滤
- **当** 用户在分类列表中选择特定分类
- **那么** 系统显示该分类的所有密码条目
- **那么** 系统更新密码条目列表

#### 场景:显示所有条目
- **当** 用户选择"所有分类"
- **那么** 系统显示所有密码条目
- **那么** 系统更新密码条目列表

### 需求:分类管理界面
系统必须提供分类管理界面。界面必须显示分类列表。界面必须提供添加、编辑、删除按钮。界面必须显示每个分类的密码条目数量。

#### 场景:分类管理界面显示
- **当** 用户打开分类管理
- **那么** 系统显示分类管理界面
- **那么** 界面显示分类列表，包含名称、颜色和条目数量
- **那么** 界面提供添加、编辑、删除按钮
