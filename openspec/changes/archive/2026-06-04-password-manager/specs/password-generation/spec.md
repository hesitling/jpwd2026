## 新增需求

### 需求:密码生成
系统必须允许用户生成高强度密码。生成时必须支持配置密码长度。生成时必须支持配置字符类型（数字、大写字母、小写字母、符号）。生成的密码必须使用密码学安全的随机数生成器。

#### 场景:生成默认密码
- **当** 用户点击生成密码按钮
- **当** 用户未修改默认配置
- **那么** 系统使用默认长度（16个字符）
- **那么** 系统使用默认字符类型（包含所有类型）
- **那么** 系统生成随机密码
- **那么** 系统显示生成的密码

#### 场景:自定义长度生成
- **当** 用户设置密码长度为20个字符
- **当** 用户点击生成密码按钮
- **那么** 系统生成20个字符的随机密码

#### 场景:自定义字符类型生成
- **当** 用户选择只包含数字和大写字母
- **当** 用户点击生成密码按钮
- **那么** 系统生成只包含数字和大写字母的随机密码

#### 场景:所有字符类型生成
- **当** 用户选择包含所有字符类型
- **当** 用户点击生成密码按钮
- **那么** 系统生成包含数字、大写字母、小写字母和符号的随机密码

### 需求:密码强度评估
系统必须评估密码强度。评估必须考虑长度、字符类型、复杂度等因素。评估结果必须分为弱、中、强、非常强四个等级。

#### 场景:弱密码评估
- **当** 用户输入少于8个字符的密码
- **那么** 系统显示强度为"弱"

#### 场景:中等密码评估
- **当** 用户输入8-11个字符的密码
- **当** 密码包含两种字符类型
- **那么** 系统显示强度为"中"

#### 场景:强密码评估
- **当** 用户输入12-15个字符的密码
- **当** 密码包含三种字符类型
- **那么** 系统显示强度为"强"

#### 场景:非常强密码评估
- **当** 用户输入16个或更多字符的密码
- **当** 密码包含所有字符类型
- **当** 密码没有重复字符
- **当** 密码没有连续字符
- **那么** 系统显示强度为"非常强"

### 需求:密码生成配置
系统必须允许用户配置密码生成默认设置。配置必须包括默认长度。配置必须包括默认字符类型。配置必须保存到配置文件。

#### 场景:配置默认长度
- **当** 用户在设置中修改默认密码长度
- **当** 用户保存设置
- **那么** 系统更新配置文件中的默认长度
- **那么** 后续生成密码使用新的默认长度

#### 场景:配置默认字符类型
- **当** 用户在设置中修改默认字符类型
- **当** 用户保存设置
- **那么** 系统更新配置文件中的默认字符类型
- **那么** 后续生成密码使用新的默认字符类型

### 需求:密码生成器界面
系统必须提供密码生成器界面。界面必须显示生成的密码。界面必须允许用户复制密码。界面必须显示密码强度指示器。

#### 场景:生成密码界面
- **当** 用户打开密码生成器
- **那么** 系统显示密码生成器界面
- **那么** 界面包含长度滑块
- **那么** 界面包含字符类型复选框
- **那么** 界面包含生成按钮
- **那么** 界面显示生成的密码
- **那么** 界面显示密码强度指示器

#### 场景:复制生成的密码
- **当** 用户生成密码后
- **当** 用户点击复制按钮
- **那么** 系统将密码复制到剪贴板
- **那么** 系统显示成功消息

### 需求:密码强度指示器
系统必须提供密码强度指示器。指示器必须可视化显示密码强度。指示器必须使用颜色编码（红、黄、蓝、绿）。

#### 场景:强度指示器显示
- **当** 用户输入或生成密码
- **那么** 系统实时计算密码强度
- **那么** 系统显示强度指示器
- **那么** 指示器颜色根据强度变化：弱（红色）、中（黄色）、强（蓝色）、非常强（绿色）

#### 场景:强度指示器更新
- **当** 用户修改密码
- **那么** 系统重新计算密码强度
- **那么** 系统更新强度指示器
