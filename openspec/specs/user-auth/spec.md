## 新增需求

### 需求:用户注册
系统必须允许新用户注册账户。注册时必须提供用户名和主密码。用户名必须唯一。主密码必须使用Argon2id算法进行哈希处理，生成的哈希值和盐值必须存储在数据库中。

#### 场景:成功注册
- **当** 用户输入唯一的用户名和有效的主密码
- **当** 用户点击注册按钮
- **那么** 系统创建用户账户，存储主密码哈希和盐值
- **那么** 系统显示注册成功消息

#### 场景:用户名已存在
- **当** 用户输入已存在的用户名
- **当** 用户点击注册按钮
- **那么** 系统显示错误消息"用户名已存在"

#### 场景:密码强度不足
- **当** 用户输入的主密码长度少于8个字符
- **当** 用户点击注册按钮
- **那么** 系统显示错误消息"密码长度必须至少8个字符"

### 需求:用户登录
系统必须允许已注册用户登录。登录时必须验证主密码。验证必须使用Argon2id算法。登录成功后必须创建会话。

#### 场景:成功登录
- **当** 用户输入正确的用户名和主密码
- **当** 用户点击登录按钮
- **那么** 系统验证主密码哈希
- **那么** 系统创建用户会话
- **那么** 系统显示主界面

#### 场景:密码错误
- **当** 用户输入正确的用户名但错误的密码
- **当** 用户点击登录按钮
- **那么** 系统显示错误消息"密码错误"

#### 场景:用户不存在
- **当** 用户输入不存在的用户名
- **当** 用户点击登录按钮
- **那么** 系统显示错误消息"用户不存在"

### 需求:会话管理
系统必须管理用户会话。登录成功后必须创建会话。会话必须包含用户ID和登录时间。会话必须存储在内存中，不持久化。

#### 场景:会话创建
- **当** 用户成功登录
- **那么** 系统创建包含用户ID和登录时间的会话
- **那么** 会话存储在内存中

#### 场景:会话销毁
- **当** 用户登出
- **当** 会话超时
- **那么** 系统销毁会话
- **那么** 系统返回登录界面

### 需求:用户登出
系统必须允许用户主动登出。登出时必须销毁会话。登出后必须返回登录界面。

#### 场景:成功登出
- **当** 用户点击登出按钮
- **那么** 系统销毁当前会话
- **那么** 系统显示登录界面

### 需求:密码哈希
系统必须使用Argon2id算法对主密码进行哈希处理。哈希时必须生成随机盐值。盐值必须与哈希值一起存储。

#### 场景:密码哈希生成
- **当** 用户注册或修改主密码
- **那么** 系统生成随机盐值
- **那么** 系统使用Argon2id算法生成密码哈希
- **那么** 系统存储哈希值和盐值

#### 场景:密码验证
- **当** 用户输入主密码进行登录
- **那么** 系统从数据库获取存储的哈希值和盐值
- **那么** 系统使用相同的Argon2id算法验证密码
- **那么** 系统返回验证结果
