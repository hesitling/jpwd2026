## 新增需求

### 需求:密码条目创建
系统必须允许用户创建新的密码条目。创建时必须提供标题和密码。密码必须使用AES-GCM-256算法加密存储。加密必须使用从主密码派生的密钥。

#### 场景:成功创建密码条目
- **当** 用户输入标题、用户名、密码、URL、备注和分类
- **当** 用户点击保存按钮
- **那么** 系统使用AES-GCM-256加密密码
- **那么** 系统生成随机初始化向量(IV)
- **那么** 系统存储加密后的密码和IV
- **那么** 系统显示成功消息

#### 场景:必填字段缺失
- **当** 用户未输入标题或密码
- **当** 用户点击保存按钮
- **那么** 系统显示错误消息"标题和密码为必填项"

### 需求:密码条目读取
系统必须允许用户查看密码条目。查看时必须解密密码。解密必须使用从主密码派生的密钥。

#### 场景:查看密码条目列表
- **当** 用户进入主界面
- **那么** 系统显示所有密码条目的列表
- **那么** 列表显示标题、用户名、URL、分类和更新时间
- **那么** 密码字段显示为掩码

#### 场景:查看密码条目详情
- **当** 用户选择特定密码条目
- **那么** 系统显示条目的所有字段
- **那么** 系统解密并显示密码
- **那么** 用户可以选择复制密码到剪贴板

### 需求:密码条目更新
系统必须允许用户更新密码条目。更新时必须重新加密密码。更新必须记录更新时间。

#### 场景:成功更新密码条目
- **当** 用户修改密码条目的任何字段
- **当** 用户点击保存按钮
- **那么** 系统重新加密密码（如果密码被修改）
- **那么** 系统更新修改时间
- **那么** 系统显示成功消息

### 需求:密码条目删除
系统必须允许用户删除密码条目。删除前必须确认。删除必须从数据库中永久移除。

#### 场景:成功删除密码条目
- **当** 用户选择删除密码条目
- **当** 系统显示确认对话框
- **当** 用户确认删除
- **那么** 系统从数据库中删除条目
- **那么** 系统显示成功消息

#### 场景:取消删除
- **当** 用户选择删除密码条目
- **当** 系统显示确认对话框
- **当** 用户取消删除
- **那么** 系统不删除条目
- **那么** 系统返回主界面

### 需求:密码条目搜索
系统必须允许用户搜索密码条目。搜索必须支持按标题、用户名和URL搜索。搜索必须实时过滤结果。

#### 场景:按标题搜索
- **当** 用户在搜索框中输入关键词
- **那么** 系统实时过滤显示标题包含关键词的条目

#### 场景:按用户名搜索
- **当** 用户在搜索框中输入关键词
- **那么** 系统实时过滤显示用户名包含关键词的条目

#### 场景:按URL搜索
- **当** 用户在搜索框中输入关键词
- **那么** 系统实时过滤显示URL包含关键词的条目

#### 场景:空搜索
- **当** 用户清空搜索框
- **那么** 系统显示所有密码条目

### 需求:密码加密存储
系统必须使用AES-GCM-256算法加密存储密码。加密必须使用从主密码派生的密钥。每次加密必须使用随机初始化向量(IV)。IV必须与加密数据一起存储。

#### 场景:密码加密
- **当** 系统存储密码条目
- **那么** 系统生成12字节随机IV
- **那么** 系统使用AES-GCM-256加密密码
- **那么** 系统将IV和加密数据组合并Base64编码
- **那么** 系统存储编码后的数据

#### 场景:密码解密
- **当** 系统读取密码条目
- **那么** 系统Base64解码存储的数据
- **那么** 系统提取IV和加密数据
- **那么** 系统使用AES-GCM-256解密密码
- **那么** 系统返回解密后的密码

### 需求:密钥派生
系统必须从主密码派生加密密钥。派生必须使用Argon2id算法。派生必须使用存储的盐值。派生的密钥必须为32字节（256位）。

#### 场景:密钥派生
- **当** 用户登录成功
- **那么** 系统从数据库获取用户的盐值
- **那么** 系统使用Argon2id算法从主密码派生密钥
- **那么** 系统在内存中存储派生的密钥
- **那么** 系统使用该密钥加密和解密密码条目
