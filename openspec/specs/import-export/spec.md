## 新增需求

### 需求:CSV导出
系统必须允许用户导出密码条目到CSV文件。导出必须包含所有密码条目。导出的密码必须是明文（解密后）。CSV文件必须使用UTF-8编码。

#### 场景:成功导出所有条目
- **当** 用户点击导出按钮
- **当** 用户选择保存位置
- **那么** 系统获取所有密码条目
- **那么** 系统解密所有密码
- **那么** 系统生成CSV文件
- **那么** 系统显示成功消息

#### 场景:导出选定条目
- **当** 用户选择特定密码条目
- **当** 用户点击导出按钮
- **当** 用户选择保存位置
- **那么** 系统只导出选定的密码条目
- **那么** 系统生成CSV文件
- **那么** 系统显示成功消息

### 需求:CSV导入
系统必须允许用户从CSV文件导入密码条目。导入时必须验证CSV格式。导入的密码必须加密后存储。导入必须处理重复条目。

#### 场景:成功导入
- **当** 用户选择CSV文件
- **当** 用户点击导入按钮
- **那么** 系统读取CSV文件
- **那么** 系统验证CSV格式
- **那么** 系统加密所有密码
- **那么** 系统存储密码条目
- **那么** 系统显示成功消息和导入数量

#### 场景:CSV格式错误
- **当** 用户选择格式错误的CSV文件
- **当** 用户点击导入按钮
- **那么** 系统显示错误消息"CSV格式错误"
- **那么** 系统指出具体错误位置

#### 场景:重复条目处理
- **当** 用户导入CSV文件
- **当** CSV文件包含已存在的条目（相同标题）
- **那么** 系统询问用户如何处理重复项
- **那么** 用户可以选择跳过、覆盖或重命名

### 需求:CSV格式规范
系统必须使用标准CSV格式。CSV必须包含标题行。CSV必须包含以下列：title, username, password, url, notes, category。列的顺序必须固定。

#### 场景:CSV文件格式
- **当** 系统导出CSV文件
- **那么** 文件第一行为标题行：title,username,password,url,notes,category
- **那么** 后续行为数据行
- **那么** 包含逗号的字段必须用双引号包围
- **那么** 包含双引号的字段必须转义

#### 场景:CSV文件编码
- **当** 系统导出CSV文件
- **那么** 文件使用UTF-8编码
- **当** 系统导入CSV文件
- **那么** 系统使用UTF-8编码读取文件

### 需求:特殊字符处理
系统必须正确处理CSV中的特殊字符。包含逗号的字段必须用双引号包围。包含双引号的字段必须转义。包含换行符的字段必须用双引号包围。

#### 场景:包含逗号的字段
- **当** 密码条目包含逗号（如密码"pass,word"）
- **那么** 系统将该字段用双引号包围
- **那么** 导出为："pass,word"

#### 场景:包含双引号的字段
- **当** 密码条目包含双引号（如密码'pass"word'）
- **那么** 系统将双引号转义为两个双引号
- **那么** 系统将字段用双引号包围
- **那么** 导出为："pass""word"

#### 场景:包含换行符的字段
- **当** 密码条目包含换行符（如备注多行）
- **那么** 系统将字段用双引号包围
- **那么** 导出为："line1\nline2"

### 需求:导入验证
系统必须验证导入的CSV文件。验证必须检查必需列是否存在。验证必须检查数据格式。验证必须提供详细的错误信息。

#### 场景:列验证
- **当** 系统导入CSV文件
- **那么** 系统检查标题行是否包含所有必需列
- **当** 缺少必需列
- **那么** 系统显示错误消息"缺少必需列：[列名]"

#### 场景:数据验证
- **当** 系统导入CSV文件
- **那么** 系统验证每行数据
- **当** 数据格式错误
- **那么** 系统显示错误消息"第X行数据格式错误"

### 需求:导入选项
系统必须提供导入选项。选项必须包括如何处理重复项。选项必须包括是否导入所有列。选项必须包括目标分类。

#### 场景:重复项处理选项
- **当** 用户导入CSV文件
- **那么** 系统显示重复项处理选项
- **那么** 选项包括：跳过、覆盖、重命名
- **那么** 用户选择处理方式

#### 场景:列选择选项
- **当** 用户导入CSV文件
- **那么** 系统显示列选择选项
- **那么** 用户可以选择导入哪些列
- **那么** 用户必须选择密码列

#### 场景:目标分类选项
- **当** 用户导入CSV文件
- **那么** 系统显示目标分类选项
- **那么** 用户可以选择导入到特定分类
- **那么** 用户可以选择保持原始分类
